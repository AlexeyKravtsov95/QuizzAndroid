# tools/design-b2 — генератор артбордов Design Gate B2

Собирает всё содержимое `docs/design/b2/`: 12 полноэкранных артбордов, 5 визуальных
state sheets и два contact sheet'а. Android-кода не содержит и не создаёт.

Генератор появился в этом проходе. Предыдущая ревизия артбордов была собрана
скриптом, который в репозиторий не попал, — поэтому её нельзя было ни проверить,
ни воспроизвести, и часть дефектов (посимвольные переносы, одна иконка на три
категории) обнаруживалась только глазами на PNG. Теперь код артбордов лежит рядом
с их результатом.

## Запуск

```
python3 tools/design-b2/generate.py      # собрать SVG + PNG + contact sheets
python3 tools/design-b2/validate.py      # проверить результат
```

Нужны `fontTools`, `cairosvg`, `Pillow`. Первый запуск скачивает шрифты и словарь
переноса в `.cache/` (в репозиторий не коммитится).

## Что откуда берётся

| Вход | Источник | Лицензия |
| --- | --- | --- |
| Noto Serif 400/500/600 | `google/fonts`, `ofl/notoserif` | SIL OFL 1.1 |
| Golos Text 400/500/600/700 | `google/fonts`, `ofl/golostext` | SIL OFL 1.1 |
| JetBrains Mono 500/700 | `google/fonts`, `ofl/jetbrainsmono` | SIL OFL 1.1 |
| Словарь переноса `hyph_ru_RU.dic` | `LibreOffice/dictionaries`, `ru_RU` | BSD 3-clause, © 1997–2008 Alexander I. Lebedev |
| Пиктограммы категорий | Material Symbols Outlined | Apache 2.0 |

Шрифты скачиваются вариативными и инстанцируются в статические веса, объявленные в
`DESIGN_TOKENS.md` §6.3. Файлы шрифтов в репозиторий не добавляются — это прямо
оговорено в том же разделе.

Пиктограммы категорий, наоборот, **зафиксированы в репозитории** как SVG-пути в
`category_icons.py`: так 10-мегабайтный иконочный шрифт не становится зависимостью
сборки, а геометрия семи иконок перестаёт зависеть от версии апстрима.

## Почему шрифты регистрируются через CoreText

Homebrew-сборка cairo на macOS ищет шрифты через quartz-бэкенд (CoreText), а не
через fontconfig, поэтому каталог с `fonts.conf` для неё невидим.
`assets.register_with_renderer()` регистрирует файлы с областью видимости
`kCTFontManagerScopeProcess` — только для текущего процесса, ничего не устанавливая
в шрифтовую библиотеку пользователя и не трогая систему.

Второе следствие: toy-API cairo различает только normal и bold и не умеет
запрашивать вес 500 или 600. Поэтому каждый вес дополнительно собирается под
собственным именем семейства («Noto Serif Medium»), и SVG пишет
`font-family="Noto Serif Medium, Noto Serif"` вместе с настоящим `font-weight`:
первое имя разрешается в этом окружении, второе — то, что использует браузер или
Compose. Без этого рендер молча откатывался бы к Regular или Bold, и метрики
артбордов не совпадали бы с приложением. `validate.py` проверяет, что в SVG нет
ни одного семейства за пределами этих девяти начертаний.

## Файлы

| Файл | Что делает |
| --- | --- |
| `tokens.py` | Значения `DESIGN_TOKENS.md`, перенесённые буквально |
| `assets.py` | Скачивание и сборка шрифтов, регистрация в рендерере |
| `hyphen.py` | Перенос по алгоритму Лианга на словаре ru_RU |
| `typeset.py` | Измерение текста по реальным TTF и разбиение на строки |
| `svgkit.py` | Примитивы SVG, форма среза угла, тени |
| `category_icons.py` | Семь пиктограмм категорий как `path` |
| `components.py` | Инвентарь `COMPONENTS.md` в отрисовке |
| `screens.py` | Четыре базовых состояния |
| `boards.py` | 12 артбордов и рамка review-board |
| `statesheets.py` | 5 визуальных state sheets |
| `generate.py` | Сборка всего + contact sheets |
| `validate.py` | Девять автоматических проверок результата |
