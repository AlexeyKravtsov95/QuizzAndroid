# ShareCard — format specification (state sheet)

Design Gate, часть B2. `ShareCard` — **не визуальный Compose-компонент**: это текстовый payload,
который строит `ShareCardBuilder` и передаёт в системный `Intent.ACTION_SEND` при нажатии
«Поделиться» на `DayRecap`. Категория «появляется на артборде» к нему неприменима по определению
(`COMPONENTS.md`, раздел «Классификация: 12 артбордов B2 и state sheets»), поэтому здесь —
невизуальная спецификация формата, а не макет и не превью карточки.

## Формат — ровно семь строк, без вариантов

```
По порядку! · День 12
15/18
🟩🟩🟩🟩🟩🟩
🟩🟩🟩🟩⬜⬜
🟩🟩🟩🟩🟩⬜
Серия: 6 дней
{APP_SHARE_URL}
```

Реализовано в PR 5D: `ui/share/ShareCardBuilder.kt` — чистый Kotlin без платформенных типов;
строки и ссылку читает `ui/share/ShareCardResources.kt`; текст уходит в системный выбор через
`ExternalApps.shareText`.

## Построчно

| № | Содержимое | Правило |
| --- | --- | --- |
| 1 | Название продукта и «День N» | `N` — порядковый номер набора пользователя (`setIndex + 1`), **не** календарная дата |
| 2 | Счёт дня «N/18» | Без пробелов вокруг «/»; сумму считает сам билдер из трёх результатов |
| 3–5 | Три строки по шесть символов | По одной строке на головоломку, по одному символу 🟩/⬜ на пару (6 пар на головоломку) |
| 6 | Серия | `Серия: N дней`; форма слова — собственное правило русского языка (`RussianPlural`), а не `plurals` по локали устройства |
| 7 | Ссылка на приложение | `{APP_SHARE_URL}` — ресурс `share_app_url`, **последняя обязательная строка**, не опциональна |

## Правила без исключений

- **Ровно семь строк.** Ни одна не опциональна и не добавляется сверх этого списка.
- **Вместо даты — «День 12».** Дата намеренно убрана: при последовательной выдаче наборов у двух
  людей в одну календарную дату разные задания, и дата создавала бы ложное ожидание общего
  задания. Номер дня честно читается как личный прогресс (`UX_FLOW.md`, раздел 6).
- **Никаких названий заданий, категорий и правильных порядков** ни в одной из семи строк —
  количество верных пар не должно выдавать содержание головоломок.
- **Эмодзи 🟩/⬜ — единственное исключение из общего запрета на эмодзи** в продукте
  (`DESIGN_PRINCIPLES.md`, раздел 8): это содержимое строки для внешнего получателя, не иконка
  интерфейса. Ни на одном экране Compose эти символы не рендерятся как UI.
- **«Поделиться» доступно только у завершённого дня** (`ITERATION_5_DESIGN.md`, **I5-D20**):
  формат требует три результата, а символа «не сыграно» в нём нет. У незавершённого дня кнопки
  нет вовсе.
- **`{APP_SHARE_URL}` не литерал в коде `ShareCardBuilder` и не название магазина.** Значение —
  нейтральный непереводимый ресурс `share_app_url` в `res/values/distribution.xml`
  (**I5-D21**, O5-6); билдер получает его параметром и никогда не формирует URL сам
  (`UX_FLOW.md`, раздел 6). **Сейчас ресурс равен `https://poporyadku.invalid/`** — одобренное
  владельцем альфа-значение на заведомо нерабочем домене RFC 2606. **Перед релизом в итерации 7
  оно обязательно заменяется** реальным URL единой landing-страницы, ведущей в RuStore и Huawei
  AppGallery; `.invalid` в release-сборке запрещён. Код названий магазинов не знает, product
  flavors ради ссылки не вводятся.
- **Три строки по шесть символов читаются моноширинно в любом мессенджере** без вложений — это и
  есть весь визуальный язык карточки, дополнительного форматирования (жирный, цвет, разметка) нет.

## Что не создаётся на этом этапе

- Визуальный Compose-превью карточки перед отправкой — в MVP не предусмотрено. Кнопка
  «Поделиться» сразу открывает системный share sheet, без промежуточного экрана
  (`COMPONENTS.md`, раздел «ShareCard»).
- Токены — `ShareCardBuilder` строит обычную Kotlin-строку, не Compose UI; типографических или
  цветовых токенов не применяет и не нуждается в них.

## Пример (иллюстративный, согласован с DayRecap на артбордах 07/08/12: 5 + 6 + 4 = 15 из 18)

```
По порядку! · День 24
15/18
🟩🟩🟩🟩🟩⬜
🟩🟩🟩🟩🟩🟩
🟩🟩🟩🟩⬜⬜
Серия: 6 дней
{APP_SHARE_URL}
```
