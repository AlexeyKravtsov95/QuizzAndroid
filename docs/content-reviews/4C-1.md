# Контентный батч 4C-1 — приёмка

Копия `docs/CONTENT_REVIEW_CHECKLIST.md`, заполненная по батчу 4C-1 (наборы 0–6).

> **Статус: выполнена только предварительная проверка агента.**
> Человеческий Content Gate **не пройден**. Все чекбоксы разделов 2–6, которые шаблон
> назначает человеку, оставлены **пустыми**: их отмечает владелец после собственного
> прохода. Раздел 7 не подписан. `verifiedBy` в контенте — `agent-4c1-precheck`,
> и это идентификатор агента, а не подпись владельца.

Ниже под каждым человеческим разделом идёт блок **«Результаты предварительной
проверки агента»** — это собранные доказательства, а не отметка о приёмке.

## 0. Что этот документ делает и чего не делает

Зелёный валидатор — необходимое условие мержа, но не достаточное. Достаточным его
делает заполненный и **подписанный человеком** чек-лист.

| Область | Кто проверяет | Раздел | Состояние |
| --- | --- | --- | --- |
| Формальная корректность | валидатор в CI | 1 | выполнено машиной |
| Достоверность источника | человек | 2 | ожидает владельца |
| Корректность утверждения: значение, единица, разрыв | человек | 3 | ожидает владельца |
| Редакционная приёмка | человек | 4 | ожидает владельца |
| Усиленный проход первых семи наборов | человек | 6 | ожидает владельца |

### Ограничение среды, повлиявшее на состав батча

Предварительная проверка выполнялась из среды, где часть привычных справочников
недоступна: `britannica.com`, `whc.unesco.org`, `loc.gov`, `usgs.gov`, `noaa.gov`,
`iucnredlist.org`, `sanparks.org`, `britishmuseum.org`, `louvre.fr`, `olympics.com`,
`kew.org`, `zsl.org` отдают 403; `cia.gov` (World Factbook) отрисовывается только на
клиенте; портал БРЭ переехал с `bigenc.ru` на `bre.ruwiki.ru`, и в этом архиве
отсутствует большинство нужных статей (`Байкал`, `Море`, `Река`, `Гора`, `Эльбрус`,
`Санкт-Петербург`, статьи о войнах — 403/404).

Темы батча подбирались под источники, которые **фактически открываются**. Следствия,
которые владелец должен оценить отдельно:

- категория `russia` в батче не используется — отдельной квоты по ней нет
  (подтверждено владельцем), а удерживать её ценой слабых источников запрещено;
- `prlib.ru` и `cyberleninka.ru`, разрешённые владельцем поштучно, в батче **не
  использованы**: страниц с нужными значениями найти не удалось, а разрешение не было
  blanket-разрешением по домену;
- Википедия используется как рабочий источник поиска и как **второй независимый**
  источник; `kind` у неё всегда `other`, и ни одной карточки она не закрывает одна.

## 1. Автоматическая проверка

```bash
python3 tools/validate-content/validate.py app/src/main/assets/content --sync-manifest
python3 tools/validate-content/validate.py app/src/main/assets/content \
    --expect-sets 7 --expect-puzzles 21
```

- [x] `--sync-manifest` выполнен после последней правки контента; повторный запуск
      печатает «манифест уже синхронизирован».
- [x] Валидатор даёт exit 0 по всему пакету.
- [x] `--expect-sets 7 --expect-puzzles 21` совпали с накопительным объёмом батча.
- [x] CI зелёный на ветке батча: run 33857570115 на коммите `0c882a88` завершился
      со статусом success, включая шаги «Validator self-check» и «Validate content pack».
- [x] Головоломки и наборы — первые в пакете; переставлять и редактировать нечего.
- [x] `contentVersion` = 1.

## 2. Достоверность источников

Пункты этого раздела отмечает **владелец**.

- [ ] Ссылка открыта лично.
- [ ] Значение найдено на странице.
- [ ] `kind` честен.
- [ ] Второй источник независим там, где он обязателен.
- [ ] У каждой карточки есть хотя бы один авторитетный источник.
- [ ] Ни один источник не выдуман.
