## 3. Корректность значений и единиц

- [x] **Единица совпадает с `sortValue`.** `length`/`height`/`depth`/`distance` — метры,
      `area` — км², `mass` — килограммы, `duration` — секунды, `year` — год
      (до н. э. — отрицательное число). Смешения единиц внутри головоломки нет ни в одной.
- [x] **Метрика внутри головоломки одна.** Проверено по каждой отдельно после замечания
      P1-2: наибольшая ширина против длины пролива, площадь зеркала против объёма озера,
      наибольшая масса взрослой особи, путь по поверхности другого тела, время от посадки
      до старта с Луны, длительность полной фазы из одной колонки каталога. Головоломка,
      где однородности добиться не удалось (гейзеры), из батча удалена, а не переформулирована.
- [x] **`displayValue` соответствует `sortValue`** и содержит единицу в том виде, в каком
      её увидит пользователь.
- [x] **Минимальный разрыв больше реальной погрешности источников.** Отдельно
      перепроверены все 15 `disputed`-карточек (разбор ниже).
- [x] **Признак имеет общепринятое значение** и не зависит от определения.
- [x] **Запрещённых в MVP признаков нет.**
- [x] **`volatility` проставлена честно.** `slow` — десять головоломок: всё, что
      измеряется (площади, ширины, глубины, длины, массы). `stable` — одиннадцать:
      каталожные значения NASA, годы событий и годы изданий.
- [x] **`disputed`** стоит там, где два актуальных источника действительно расходятся,
      и всегда сопровождается `note` с обоими значениями.
- [x] **`sortKey` — из девяти разрешённых.**

## 4. Редакционная приёмка

Ниже — суждение агента, а не человека.

- [x] **Формулировка однозначна.** Каждый `prompt` называет и класс объектов, и признак,
      и точку отсчёта («по наименьшей ширине», «по наибольшей длине», «по пути,
      пройденному вне Земли», «по времени пребывания на Луне»).
- [x] **Альтернативный порядок невозможно разумно обосновать** — проверено через разбор
      `disputed` (раздел 3).
- [x] **`prompt`** — до 90 символов, повелительное наклонение. Самый длинный — 68 символов.
      После замечаний P2-1 и P2-5 два `prompt` уточнены так, чтобы называть класс объектов
      честно: «**ранние** пилотируемые космические полёты» и «**объекты системы**
      национальных парков США по **общей** площади».
- [x] **`explanation` объясняет причину, а не пересказывает порядок.** Ни одно объяснение
      не содержит причинных утверждений, которых нет в процитированных страницах:
      где механизм не подтверждён источником, оставлено определение метрики и сопоставление
      величин. Все отношения «в N раз» и все проценты пересчитаны программно.
- [x] **Тон нейтральный.**
- [x] **Типографика:** тире «—», кавычки-ёлочки, «ё», неразрывный пробел между числом
      и сокращённой единицей; перед словами «год», «лет», «мин», «ч» — обычный пробел,
      как в батчах 4C-1…4C-3.
- [x] **Орфография проверена** вычиткой всех объяснений и подписей.
- [x] **`verifiedAt` и `verifiedBy` заполнены фактически:** `2026-09-07` у четырнадцати
      головоломок и `2026-09-10` у семи пересмотренных по ревью; `verifiedBy` везде
      `agent-4c4-precheck`. Это идентификатор агента, а **не** подпись владельца.
