## 3. Корректность значений и единиц

- [x] **Единица совпадает с `sortValue`.** `length`/`height`/`depth`/`distance` — метры,
      `area` — км², `mass` — килограммы, `duration` — секунды, `year` — год. Проверено
      построчно; смешения единиц внутри головоломки нет ни в одной.
- [x] **`displayValue` соответствует `sortValue`.** Там, где источник даёт другую единицу
      (футы, мили, карат нет), пересчёт указан в `note` источника; пользователь видит
      метрическую величину.
- [x] **Минимальный разрыв больше реальной погрешности.** Отдельно перепроверены все
      восемь `disputed`-карточек: ни в одной расхождение источников не съедает разрыв
      до соседа (разбор — ниже).
- [x] **Признак имеет общепринятое значение.** Все признаки числовые и определены
      однозначно: длина горной системы по её оси, наибольшая зарегистрированная глубина
      погружения, наибольшая масса взрослой особи, длина главного пролёта, диаметр
      главного зеркала, высота площадки над уровнем моря, площадь водосборного бассейна.
- [x] **Запрещённых в MVP признаков нет.** Нет субъективных, спорных по приоритету,
      политически чувствительных и быстро меняющихся.
- [x] **`volatility` проставлена честно.** `slow` — там, где значение уточняется
      измерениями (7 головоломок: горные системы, длина китообразных, глубина погружения,
      масса черепах, масса пингвинов, глубина озёр, площадь бассейнов). `stable` — годы,
      размеры построек и приборов, константы CODATA, астрономические расстояния.
- [x] **`disputed`** стоит ровно там, где два актуальных источника действительно
      расходятся, и всегда сопровождается `note` с обоими значениями.
- [x] **`sortKey` — из девяти разрешённых.** `date`, `population`, `temperature`,
      `latitude`, `longitude` не используются.
