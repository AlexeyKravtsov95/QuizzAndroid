пятого и последнего редакционного батча итерации 4. Даты работы (UTC): первый проход и
правки по ревью владельца — **2026-09-10**. Предварительную проверку выполнил

**Статус: автоматическая и редакторская предварительная проверка выполнена; независимый
Content Review ещё требуется.** Ни один пункт, требующий человека, ниже не отмечен как
выполненный человеком: там, где проверку делал агент, это сказано прямо. Владелец не обязан

## 3. Корректность значений и единиц

- [x] **Единица совпадает с `sortValue`.** `height`/`depth`/`length`/`distance` — метры,
      `mass` — килограммы, `speed` — км/ч, `duration` — секунды, `year` — годы.
- [x] **Метрика внутри головоломки одна.** Проверено по каждой: высота холста (первое число
      музейного «высота × ширина»), водоизмещение по одной таблице оператора, первая
      постановка (а не редакция), полный полярный день по датам ААНИИ, год основания по
      сайту самого заповедника, пройденная глубина скважины, полная высота сооружения
      (Бранденбургские ворота — с квадригой, и это сказано в подписи), год рождения,
      нижняя граница балла Бофорта, наибольший известный возраст по «Quick Facts» NOAA,
      наибольшая достигнутая скорость, глубина места, где корабль лёг на дно, длина по
      DANFS, период обращения, год, когда вспышку увидели с Земли, длина дистанции, размах
      крыла, полная высота колеса, наибольшая глубина жёлоба.
- [x] **`displayValue` соответствует `sortValue`** и содержит единицу; число и сокращённая
      единица разделены неразрывным пробелом.
- [x] **Минимальный разрыв больше реальной погрешности источников** (таблица ниже;
      расхождения — отдельно).
- [x] **Признак имеет общепринятое значение** и не зависит от определения; где значение
      зависит от определения, определение названо в `prompt` («по полной высоте», «по
      нижней границе скорости», «по году выхода первого издания», «по глубине, на которой
      они легли на дно»).
- [x] **Запрещённых в MVP признаков нет** (`date`, `population`, `temperature`, `latitude`,
      `longitude` — ни одного).
- [x] **`volatility` проставлена честно.** `slow` — три головоломки, где значение
      уточняется измерением или оценкой: глубины жёлобов, периоды комет, наибольший
      возраст рыб. `stable` — восемнадцать: годы событий и изданий, паспортные размеры
      сооружений, судов и самолётов, пройденные глубины скважин, границы шкалы Бофорта,
      даты полярного дня по координатам станций.
- [x] **`disputed`** стоит там, где два источника действительно расходятся, всегда с `note`.
- [x] **`sortKey` — из девяти разрешённых.**

## 4. Редакционная приёмка

Ниже — суждение агента, а не человека.

- [x] **Формулировка однозначна.** Каждый `prompt` называет класс объектов и признак, а

      порядок?»; где ответ был «да», формулировка менялась (раздел «Заменённые

- [x] **Альтернативный порядок невозможно разумно обосновать** — проверено разбором

- [x] **`prompt`** — до 90 символов, повелительное наклонение; самый длинный — 75 символов

- [x] **Подписи не выдают ответ.** Проверено отдельно: у сверхновой 1006 года название

## 8. Сомнения для независимого ревьюера

1. **Larousse — пять головоломок из 21** (`097`, `102`, `103` целиком; `091` и `099`
   частично). Treccani в батче нет, но зависимость от одной энциклопедии в меньшем масштабе
   сохранилась. Устаревшие глубины Пуэрто-Рико и Тонги из Larousse по ревью заменены
   значениями *Geoscience Data Journal* (раздел 0.1).
2. **Принято владельцем.** **`area` в батче нет ни разу, `year` — шесть раз**, и наборы 29–34 подряд содержат по
   одной годовой теме. Это самое заметное отклонение от ориентиров по признакам.
3. **Принято владельцем.** **`russia` — 6 вместо 7, `nature` — 2 вместо 3.** Итоговый диапазон 14–16 совпадает с
   целевым, но за счёт `history` и `mixed`.
4. **Принято владельцем** (порог пройден, значения паспортные). **Колёса обозрения (`111`) — разрывы 3,6 % и 7,3 %.** Формально проходит, значения
   паспортные, но для игрока две пары близки. Стоит решить, не заменить ли «Лондонский
   глаз» или «Солнце Москвы».
5. **Сайт Росатомфлота (`092`) прочитан с отключённой проверкой TLS-цепочки.** Если
   ревьюер не сможет открыть страницы в браузере, значения водоизмещения нужно подтвердить
   другим официальным источником. Отдельно: у «Ямала» взято значение строки «Тип АРКТИКА»,
   а не индивидуальный паспорт судна.
6. **Принято владельцем** (visitBerlin прямо называет себя официальным туристическим порталом Берлина). **visitBerlin (`099`) классифицирован как `official`.** Это туристическое агентство
   земли Берлин, а не управление памятником; у карточки есть второй источник
   (Википедия), но если ревьюер сочтёт `kind` завышенным, карточке понадобится другой
   авторитетный источник.
7. **`107` — закрыто по ревью.** Критерий теперь «глубина обнаружения обломков», у
   «Джонстона» явно указана носовая часть. Оставшаяся оговорка: у «Васы» 32 м — глубина,
   на которой корабль лёг на дно в 1628 году; позднее корабль подняли.
8. **`105`: «пройденная глубина» скважин.** Для наклонных скважин длина ствола и
   вертикальная глубина различаются; в выбранных статьях для всех четырёх скважин приведено
   одно число глубины без оговорки о вертикали. Ревьюеру стоит это подтвердить.
9. **`098`: длительность полярного дня посчитана включительно** по датам ААНИИ. При
   подсчёте «без последнего дня» все значения уменьшаются на сутки, порядок не меняется.
10. **`102`: «первое издание» у многотомных собраний** — год выхода первого выпуска
    (Андерсен 1835–1872, Афанасьев 1855–1864). Это сказано в `prompt` и в `note`.
11. **`095`: «Спартак» — постановка 1956 года в Театре им. Кирова**, как её называет
    Мариинский театр. Широко известная постановка Григоровича (Большой, 1968) — не первая;
    формулировка «по году первой постановки» это покрывает, но пользователь, знающий
    только версию Большого, может ошибиться.
12. **`109`: подписи-описания ветров** («Ломает сучья деревьев», «Срывает черепицу»)
    помогают восстановить порядок. Это сделано сознательно — головоломка стоит в слоте 0 с
    `difficulty 1`, — но ревьюер может счесть подсказку слишком прямой.
13. **Ни одна ссылка батча не открыта владельцем** — по условиям задачи это не требуется;
    окончательное решение принимает внешний ревьюер.
